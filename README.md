# Google Play Store – App Insights Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on Google Play Store application data using Python. The objective is to understand app distribution, ratings, reviews, installations, pricing and other application characteristics.

## Project Objectives
- Analyze Google Play Store application data.
- Understand app category distribution.
- Explore application ratings and reviews.
- Compare free and paid applications.
- Analyze app installations and pricing patterns.
- Identify trends through data visualization.

## Dataset
- **File:** `googleplaystore.csv`
- **Source:** Google Play Store application dataset.
